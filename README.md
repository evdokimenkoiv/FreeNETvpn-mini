# FreeNETvpn-mini

Лёгкий VPN-сервер с преднастроенными **WireGuard** и **VLESS REALITY**, установкой одной командой и локальной панелью управления.

Проект работает напрямую через systemd: без Docker, Caddy, базы данных, домена и SSL/TLS-сертификата. Панель доступна только через SSH-туннель и не публикуется в интернете.

## Возможности

- WireGuard с автоматической настройкой NAT и firewall.
- VLESS TCP + REALITY + Vision на базе Xray.
- Создание, перевыпуск и удаление клиентов из панели.
- Скачивание WireGuard-профилей, VLESS JSON и копирование VLESS-ссылок.
- Статусы сервисов, handshake и трафик WireGuard, диск и память.
- Сохранение ключей, клиентов, настроек и пароля при повторной установке или обновлении.

## Требования

- **Ubuntu 22.04/24.04/26.04 LTS**, архитектура **x86_64**, systemd.
- root или sudo, публичный IPv4 и доступ сервера к GitHub.
- Открытые на провайдерском firewall порты **UDP 51820** и **TCP 443**, если используются значения по умолчанию.

| Ресурс | Минимум | Рекомендуется |
|---|---:|---:|
| Свободное место на `/` перед установкой | **1 ГиБ** | **2 ГиБ и больше** |
| Общий размер диска VPS | **8 ГиБ** | **10–20 ГиБ** |
| RAM | **512 МиБ** | **1 ГиБ** |
| CPU | **1 vCPU** | **1 vCPU** |

Сам проект ориентировочно добавляет 150–350 МиБ к базовой системе. Основной расход диска обычно дают Ubuntu, системные обновления и журналы. Для VPS с 512 МиБ RAM желательно заранее включить swap на 512 МиБ–1 ГиБ.

## Установка одной командой

Выполните на сервере:

```bash
sudo bash -c 'set -e; apt-get update -qq; apt-get install -y --no-install-recommends ca-certificates curl; f=$(mktemp); trap "rm -f -- \"$f\"" EXIT; curl -fsSL https://raw.githubusercontent.com/evdokimenkoiv/FreeNETvpn-mini/main/install.sh -o "$f"; bash "$f"'
```

Установщик проверит систему и свободное место, установит необходимые пакеты и закреплённую версию Xray, проверит её SHA-256, создаст ключи и клиентские профили, настроит UFW и запустит сервисы. В конце будут показаны данные первого подключения и пароль панели — сохраните их.

Проект устанавливается в `/opt/freenetvpn-mini`. Повторный запуск не пересоздаёт существующие секреты и пароль.

### Собственный адрес сервера

Если публичный IPv4 определяется неправильно или используется DNS-имя:

```bash
sudo SERVER_HOST=vpn.example.com bash -c 'set -e; apt-get update -qq; apt-get install -y --no-install-recommends ca-certificates curl; f=$(mktemp); trap "rm -f -- \"$f\"" EXIT; curl -fsSL https://raw.githubusercontent.com/evdokimenkoiv/FreeNETvpn-mini/main/install.sh -o "$f"; bash "$f"'
```

Если UFW управляется отдельно, после установки можно повторно применить конфигурацию без изменения firewall:

```bash
sudo bash /opt/freenetvpn-mini/install.sh --no-firewall
```

## Получение подключений

Вывести все WireGuard-профили и VLESS-ссылки на сервере:

```bash
sudo bash /opt/freenetvpn-mini/scripts/show-clients.sh
```

Файлы первого клиента:

```text
/opt/freenetvpn-mini/clients/wireguard/client1.conf
/opt/freenetvpn-mini/clients/vless/client1.txt
/opt/freenetvpn-mini/clients/vless/client1.json
```

Импортируйте `.conf` в официальное приложение WireGuard. VLESS-ссылку или JSON используйте в клиенте с поддержкой **VLESS TCP + REALITY + Vision**. Предоставленный JSON создаёт локальный SOCKS5-прокси `127.0.0.1:1080`.

Чтобы сохранить WireGuard-профиль на локальный компьютер, выполните **на локальном компьютере**:

```bash
ssh <ssh-user>@ВАШ_СЕРВЕР 'sudo cat /opt/freenetvpn-mini/clients/wireguard/client1.conf' > client1.conf
chmod 600 client1.conf
```

## Панель управления

Панель слушает только `127.0.0.1:8080`. Открывать порт 8080 в UFW или на провайдерском firewall не нужно.

### 1. Создайте SSH-туннель

На локальном компьютере:

```bash
ssh -N -L 8080:127.0.0.1:8080 <ssh-user>@ВАШ_СЕРВЕР
```

Оставьте команду запущенной. Если SSH использует нестандартный порт, добавьте `-p ПОРТ`.

Если локальный порт 8080 занят:

```bash
ssh -N -L 18080:127.0.0.1:8080 <ssh-user>@ВАШ_СЕРВЕР
```

### 2. Откройте панель

Перейдите на [http://127.0.0.1:8080](http://127.0.0.1:8080) или `http://127.0.0.1:18080` для альтернативного туннеля.

- **Логин:** `admin`.
- **Пароль:** показан установщиком.

Если пароль потерян, создайте новый на сервере:

```bash
sudo python3 /opt/freenetvpn-mini/panel/server.py --reset-password
```

Перезапуск панели после сброса пароля не требуется.

## Управление клиентами и ключами

В разделе **«Клиенты и подключения»** доступны следующие операции:

- **Создать ключи** — выберите протокол и укажите имя. Без имени будет создан `clientN`.
- **Скачать** — получить WireGuard `.conf`, VLESS `.txt` или `.json`.
- **Копировать** — скопировать VLESS-ссылку выбранного клиента.
- **Перевыпустить** — заменить ключи только выбранного клиента. Его старая конфигурация перестанет работать, остальные клиенты не изменятся.
- **Удалить** — удалить доступ и файлы клиента. Последнего клиента протокола удалить нельзя.

Имя может содержать строчные `a-z`, цифры, `-` и `_`, до 32 символов. Можно создать до 100 клиентов на протокол. Каждый WireGuard-клиент получает отдельный адрес, каждый VLESS-клиент — отдельные UUID и short ID.

После операции панель обновляет только нужную серверную конфигурацию и перезапускает соответствующий сервис.

## Обновление

На сервере с существующей установкой:

```bash
sudo bash -c 'set -e; f=$(mktemp); trap "rm -f -- \"$f\"" EXIT; curl -fsSL https://raw.githubusercontent.com/evdokimenkoiv/FreeNETvpn-mini/main/scripts/update.sh -o "$f"; bash "$f"'
```

Команда загружает актуальный код и повторно применяет конфигурацию. Каталог `data`, файл `.env`, клиенты, ключи и пароль панели сохраняются. Во время перезапуска сервисов VPN-подключения могут ненадолго прерваться.

После обновления откройте панель заново или нажмите **Ctrl+F5**.

## Настройки

Основные параметры находятся в `/opt/freenetvpn-mini/.env`; пример — в [.env.example](.env.example). Секреты хранятся отдельно в `data/state.json`.

После изменения `.env` примените настройки:

```bash
sudo bash /opt/freenetvpn-mini/install.sh
```

Клиентские файлы будут перегенерированы с теми же ключами. Для перевыпуска ключей отдельных клиентов используйте панель, а не ручное редактирование `state.json`.

## Проверка и диагностика

```bash
sudo bash /opt/freenetvpn-mini/scripts/health.sh
systemctl status wg-quick@wg0 freenetvpn-xray freenetvpn-panel
journalctl -u freenetvpn-xray -u freenetvpn-panel -n 50 --no-pager
```

При проблемах с подключением проверьте:

1. Открыты ли UDP-порт WireGuard и TCP-порт VLESS на провайдерском firewall.
2. Совпадает ли `SERVER_HOST` в клиентском профиле с публичным адресом сервера.
3. Активны ли все три systemd-сервиса.
4. Не перехватываются ли VPN-порты другим приложением или HTTP-прокси.

## Данные и безопасность

- Панель принимает соединения только на loopback и требует авторизацию.
- Пароль панели хранится как PBKDF2-SHA256-хеш, а не в открытом виде.
- WireGuard и VLESS REALITY не требуют домена и собственного SSL/TLS-сертификата.
- Каталоги `data`, `clients` и файл `.env` содержат секреты и не входят в репозиторий.
- Для резервной копии сохраните их на отдельном защищённом носителе.
